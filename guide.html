1만들게 된 이유

매달 달라지는 근무 시간과 복무관리를 보다 효율적으로 관리하기 위해 만들었습니다.

교대근무는 달마다 당번 횟수와 휴일이 다르고, 보근·연가·출장·조퇴까지 겹치면 이번 달 근무 시간과 수당을 따로 정리하기가 번거롭습니다. 그래서 달력에 그날의 복무 상황만 적으면 근무 시간과 예상 수당이 자동으로 정리되도록, 현직 소방관이 직접 만든 앱입니다.

같은 고민을 하는 동료들과 함께 쓰고 다듬어 가려고 베타 버전으로 공개합니다.

2이런 점이 좋아요

💰 예상 수당을 바로 확인시간외·야간·휴일 수당을 계급별 단가로 자동 계산합니다. 1시간 미만 절삭, 휴일 차감, 공동근무 20분까지 반영해요.
📅 복무관리가 쉬워요당비휴·주야비휴(상황실)·일근 근무표가 달력에 자동으로 깔리고, 보근·출장·교육·휴가·조퇴·지각·외출·당직을 날짜만 눌러 기록합니다.
🔄 인사이동·승진해도 기록이 이어져요팀이나 근무 방식, 계급이 바뀌면 적용일만 넣으세요. 이전 기록은 그대로 보관되고, 바뀐 팀과 계급으로 이어서 관리됩니다.
📝 날짜별 개인 메모출동 내용, 준비물, 기억할 일 등을 날짜마다 적어둘 수 있어요.
📊 월별·연도별 통계1년 동안의 월별 수당과 총액, 해마다의 증감을 한눈에 볼 수 있어요.
📱 설치 파일 없이 무료앱스토어 없이 홈 화면에 추가만 하면 앱처럼 쓰고, 업데이트도 자동입니다.

3설치 방법 (1분)

📱 안드로이드 (갤럭시 등)
  1. 크롬으로 이 페이지의 앱 바로 열기를 누릅니다.
  2. 오른쪽 위 ⋮ 메뉴 → 앱 설치 또는 홈 화면에 추가를 누릅니다.
  3. 홈 화면에 생긴 빨간 ‘근무’ 아이콘으로 실행합니다.
🍎 아이폰
  1. 반드시 사파리로 이 페이지의 앱 바로 열기를 누릅니다.
  2. 아래쪽 공유 버튼(네모에 위쪽 화살표) → 홈 화면에 추가를 누릅니다.
  3. 홈 화면에 생긴 빨간 ‘근무’ 아이콘으로 실행합니다.

처음 실행하면

  1. 근무 방식(당비휴·주야비휴·일근)과 계급을 고릅니다.
  2. 교대근무라면 아무 날짜 하나와 그날 내 근무(당번·비번·휴무 등)를 고르면 달력이 맞춰집니다.
  3. 날짜를 눌러 보근·휴가 등을 입력하고 확인을 누르면 끝!
카카오톡 등에서 링크를 열었다면, 오른쪽 아래·위 메뉴의 다른 브라우저로 열기로 크롬(안드로이드)이나 사파리(아이폰)에서 다시 열어 설치하세요.

4꼭 알아두세요

  • 내 기록은 내 휴대폰에만 저장됩니다. 서버로 전송되지 않아 만든 사람을 포함해 누구도 볼 수 없어요. 로그인도 없습니다.
  • 그래서 앱 삭제, 브라우저 데이터 삭제, 휴대폰 교체 시 기록이 사라질 수 있어요. 가끔 설정 → 데이터 백업·복원 → 백업 코드 복사로 백업 코드를 메모장이나 ‘나에게 보내기’에 저장해 두세요.
  • 설치한 아이콘으로만 사용하세요. 특히 아이폰은 사파리 창과 홈 화면 앱의 기록이 따로 저장됩니다.
  • 계산 결과는 참고용 추정치입니다. 실제 지급액은 e-사람 확정 실적과 보수명세서를 기준으로 하세요.
  • 단가는 공무원수당 등에 관한 규정·공무원보수규정 기준으로 계산하며, 당직비는 시·도마다 달라 설정에서 직접 맞춰야 합니다.
  • 개인이 만든 비공식 앱으로, 소방청·소방본부의 공식 시스템이 아닙니다.
메모에 대상자 이름·주소 같은 남의 개인정보는 적지 않는 것을 권장합니다.

5오류 제보·개선 요청

베타 버전이라 여러분의 의견이 가장 큰 도움이 됩니다. 계산이 실제와 다르거나, 불편한 점·추가했으면 하는 기능이 있으면 알려주세요.

  1. 앱에서 설정 → 맨 아래 ‘의견 보내기’를 누르면 접수 양식이 열립니다.
  2. 앱 버전과 근무 방식이 자동으로 복사되니, 양식에 붙여넣어 주세요.
  3. 계산 오류라면 그달 e-사람 실적(시간외·야간·휴일)과 앱 결과를 함께 적어주시면 빠르게 고칠 수 있어요.
